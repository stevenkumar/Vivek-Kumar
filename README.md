## ⚡ Architecture & Highlights

- **100% Frontend Client-Side Architecture:** Zero backend dependencies. Contact messages are delivered directly via **Web3Forms API**.
- **React 19 & TypeScript Strict Mode:** Full type safety across components, interfaces, and theme configurations.
- **Tailwind CSS v4:** Powered by `@tailwindcss/vite` and dynamic CSS custom properties for instant zero-flicker theme customization.
- **Fluid Micro-Animations:** Orchestrated through **Framer Motion** (`AnimatePresence`, physics-based drawers, layout transitions).
- **Interactive 3D Orbital Timeline:** Interactive radial orbital canvas mapping professional milestones, core skills, and engineering products.
- **Developer CLI Terminal:** In-browser interactive Bash terminal emulator supporting quick-launch commands (`github`, `linkedin`, `skills`, `resume`, `whoami`).

## 💻 Local Development Setup

### Prerequisites
- Node.js `18.x` or higher
- npm `9.x` or higher

### Installation & Run

```bash
# 1. Clone the repository
git clone https://github.com/stevenkumar/Vivek-Kumar.git
cd Vivek-Kumar

# 2. Install dependencies
npm install

# 3. Configure environment variables
# Copy .env.example to .env and set your Web3Forms access key
cp .env.example .env

# 4. Start the local Vite development server
npm run dev

# 5. Typecheck & build production bundle
npm run build

# 6. Preview production build locally
npm run preview
```
